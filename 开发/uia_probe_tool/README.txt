UIA Probe Tool v1.0 使用说明
=====================================================

【用途】
本工具用于在工作电脑（无 Python 环境）上探测目标窗口的 UIA 控件树，
把结果输出为 txt 文件，传回开发机分析。当前用于定位紫鸟浏览器
A419 广告计划列表页"筛选刷新"不生效的根因——即确认页面上的
"状态筛选框 / 已生效选项 / 应用按钮"在 UIA 视角下到底是什么控件、
叫什么名字、带哪些可交互接口（Patterns）。

=====================================================
【运行步骤】
1. 在紫鸟浏览器中打开 A419 广告计划列表页，保持页面处于前台可见；
2. （可选，强烈建议）先手动点击展开页面上方的"状态"筛选下拉框，
   让下拉选项显示出来（这样探测到的控件树会包含下拉选项的节点）；
3. 双击运行 UIAProbe.exe（黑色 console 窗口出现）；
4. 工具会自动尝试匹配标题含 "A419" 的窗口；
   - 若自动匹配成功，直接回车确认（或等待自动开始）；
   - 若未匹配到，工具会列出当前所有可见窗口，输入序号选择目标窗口；
5. 等待扫描（大页面可能需要 10~60 秒），完成后 console 显示摘要；
6. 在 UIAProbe.exe 所在目录找到 uia_probe_<时间戳>.txt 报告文件，
   把该文件传回开发机即可。

【重要提示：跑两次】
- 第一次：页面保持默认状态直接运行，得到"未展开下拉"的控件树；
- 第二次：手动展开"状态"筛选下拉后再次运行，得到包含下拉选项的控件树；
- 两份文件都传回，便于对比定位筛选刷新不生效的原因。

=====================================================
【报告内容】
uia_probe_<时间戳>.txt 包含：
1. 探测时间、目标窗口句柄/标题/类名/PID；
2. 控件总数、关键词命中数；
3. 【关键词命中清单】：Name 含「状态/筛选/已生效/生效/应用/确定/全部」
   的控件，一眼定位筛选相关控件；
4. 【完整控件树】：每个控件一行，层级缩进，包含
   ControlType、Name、AutomationId、ClassName、矩形坐标、可用 Patterns。

【常用 Patterns 含义】
- Invoke        ：可点击（按钮类操作）
- SelectionItem ：可选中（列表项/单选/下拉选项）
- ExpandCollapse：可展开/收起（下拉框、折叠面板）
- Toggle        ：可切换开关状态
- LegacyIAccessible：提供旧版无障碍接口（自动化工具常用）

=====================================================
【命令行参数（可选）】
UIAProbe.exe --keyword A419          # 指定关键词自动匹配
UIAProbe.exe --keyword A419 --max-depth 14 --max-nodes 3000
                                     # 限制深度与控件总数（防止超大页面卡死）
默认交互模式：直接双击运行即可。

=====================================================
【故障排查】
- 双击后窗口闪退：请用命令行方式运行 UIAProbe.exe 查看报错信息；
- 扫描很慢或卡住：可加大 --max-nodes，或确认页面已加载完成；
- 找不到目标窗口：确认窗口标题含 A419，或用 "list" 手动选择；
- 输出的 txt 是 UTF-8 编码，用记事本打开即可正常显示中文。
