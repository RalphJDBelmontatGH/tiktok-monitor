# TK 投流网页监控程序

> 无人值守 + 命中才告警。截图 + 本地 OCR 采集后台数据，止损线命中时推微信（方糖 Server酱）+ Windows 通知。
> 不碰网页 DOM、不注入脚本、无爬虫请求——与真人看屏幕无异，不触发反爬、不封店。

## 目录结构

| 文件 | 说明 |
|------|------|
| `main.py` | 主程序（含 GUI、采集、规则、告警、报告、标定） |
| `requirements.txt` | Python 依赖清单 |
| `INSTALL_PYTHON.bat` | 一键安装依赖（需已装 Python 3.9+） |
| `START.bat` | 启动程序 |
| `CLEAN.bat` | 快速清理（删截图/数据/配置，保留程序） |
| `彻底清理.bat` | 彻底清理/自毁（删整个目录，输入 DELETE 确认） |
| `config.json` | 配置（首次保存后生成） |
| `data.json` | 采集数据（JSON） |
| `state.json` | 状态（告警冷却、CVR 观察期） |
| `ocr_debug/` | 截图调试目录（每次采集的字段截图） |
| `reports/` | 报告输出（文本 + 24h 四宫格曲线图） |

## 安装

1. 安装 Python 3.9+（[python.org](https://www.python.org/downloads/)），安装时勾选 **Add Python to PATH**
2. 双击 `INSTALL_PYTHON.bat` 等待依赖装完
3. 双击 `START.bat` 启动

## 三步上手

### 第 1 步：标定识别区域
1. 打开 TK 投流后台网页，窗口保持还原（不要最小化）
2. 启动程序 → 点「标定识别区域」
3. 选择字段（成本/收入/订单/UV）→ 在窗口截图上拖拽框选对应数字区域 → 保存
4. 依次标定 4 个字段（至少标定 **成本 + 收入或订单** 两项）
5. 标定坐标是相对窗口的，后台窗口移动后依然有效

### 第 2 步：测试 OCR
- 点「立即采集一次」
- 看日志是否打印 `已入库: 成本=... 收入=... ROI=...`
- 若提示「OCR 识别不足」，说明区域没框准或框到非数字区域，重新标定，或先用手动录入

### 第 3 步：启动自动监控
1. 填好方糖 SendKey（[sct.ftqq.com](https://sct.ftqq.com/) 获取，免费版每天 5 条，命中才推够用）
2. 设置采集间隔（≥5 分钟，默认 60；风控起见建议 5~15 分钟）
3. 点「开始监控」
4. 后台窗口保持可见，**关闭锁屏/息屏**，否则截屏是黑屏

## 止损线规则（命中即告警）

| 层级 | 触发条件 | 动作 |
|------|---------|------|
| 转化率线 | CVR < 0.5% | 第 1 天标注观察不推；连续第 2 天仍低 → 推「换品/换视频」 |
| 成本线 | 成本 > 客单价 × 2（默认客单 15 → 30） | 立即推「止损」；消耗过多建议关闭并重建计划 |
| 个人红线 | 空烧 ≥ 5（有消耗且无订单/收入） | 立即推「立即停」 |
| 空烧红灯 | 消耗速率 > 0.5$/分 且无订单/收入 | 推「空烧红灯」 |

- 同规则告警有 30 分钟冷却，命中才推、不刷屏
- ROI 异常（>10 或 <0）**不自动入库**，弹窗要求手动确认

## 可见性 & 可控性（§4.3 硬性要求）

程序**永远可见、随时可停、状态可感知**：

- **常驻可见窗口**：主窗口顶部「运行状态」栏实时显示 状态机阶段（采集中/比对中/告警中/等待中/已停止）、上次采集时间、下次采集倒计时、累计记录数、告警开关状态

- **一键静音**：点「静音告警」后推送全部暂停（微信+Windows通知），再点恢复；静音状态持久化，重启不丢

## 常用问题 Q&A

**Q1：找不到窗口 / 提示窗口标题不匹配？**
后台窗口标题里必须含配置的「窗口关键字」（默认 TikTok）。可在程序里改，或把浏览器窗口标题改成含 TikTok 的。

**Q2：识别到的数字不对？**
重新标定更小的区域，只框数字本身，别框标签文字。OCR 对纯数字和 `$12.34` 识别最稳。

**Q3：监控期间屏幕能不能做别的事？**
能，但后台窗口必须保持可见、不被遮挡、不最小化、不锁屏。建议用单独一台电脑/一个显示器跑监控。

**Q4：多久采集一次合适？**
风控角度 ≥5 分钟起步；要抓空烧早期建议 5~10 分钟。太频繁会显得不自然。

**Q5：方糖免费版够用吗？**
够。免费版每天 5 条，告警是"命中才推"，一天正常不会超过 5 条。要更稳可换付费或钉钉机器人（免费无限）。

**Q6：怎么确认没有封店风险？**
程序只做两件事：屏幕截图 + Windows 本地 OCR，不产生任何网络请求（除方糖推送）。和真人盯着屏幕看完全一样，不触发反爬。

**Q7：我不想跑了怎么清干净？**
日常下班跑 `CLEAN.bat`（快速清理）；想彻底消失跑 `彻底清理.bat`，输入 `DELETE` 确认，5 分钟内清干净。

**Q8：点关闭按钮程序会退出吗？**
不会。点 X 只是最小化到系统托盘（右下角），监控仍在跑；要彻底退出请用托盘菜单「退出程序」或先点「停止监控」再关闭。

**Q9：深夜不想被告警吵醒怎么办？**
点「静音告警」一键静音（微信+通知都不推），早上再点「恢复告警」。静音状态重启程序也保持。

**Q10：怎么看程序现在在干嘛？**
主窗口「运行状态」栏：阶段（采集中/比对中/告警中/等待中）、上次采集时间、下次采集倒计时、累计记录数，一目了然。
